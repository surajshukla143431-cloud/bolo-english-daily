BOLO ENGLISH DAILY - phone app (PWA)

Files: index.html, manifest.webmanifest, sw.js, 3 icons. Sab ek hi folder mein rehni chahiye.

STEP 1 - Online daalo (ek baar, laptop se)
  Option A (sabse aasaan): app.netlify.com/drop kholo, is folder ko drag-drop karo. Ek https link milega.
  Option B: GitHub par naya repo banao, files upload karo, Settings > Pages se chalu karo.
  Mic aur "Install app" ke liye https link zaroori hai.

STEP 2 - Phone par install
  Chrome mein link kholo > menu (teen dots) > Install app / Add to Home screen.

STEP 3 - AI coach chalu karo
  App mein Progress tab > "Claude API key" mein key daalo > Save > Test karo.
  Key: console.anthropic.com > API keys (credits daalne padte hain). Key sirf aapke phone mein save hoti hai.

STEP 4 (optional) - APK
  pwabuilder.com par apna https link daalo > Package for stores > Android > Download. APK ko phone mein install karo
  (Settings mein "Install unknown apps" allow karna padega).
